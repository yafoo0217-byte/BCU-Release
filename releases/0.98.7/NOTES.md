## Stage VS v0.98.7: 휴대폰용 전체 묶음

고화질 내보내기 창에 **`휴대폰용 전체 묶음: 아군 전부 / 적 전부 / 배경 전부`**가 생겼어요. 게임의 모든 아군(모든 형태), 적, 배경을 번호와 이름과 함께 약 80MB짜리 zip 여러 개(`BCU 폴더/img/휴대폰 묶음/`)로 묶어요(몇 분 걸려요). 휴대폰 페이지 **냥코 애니 GIF 공방**의 `묶음 넣기`로 한 번 넣으면, 그다음부터는 번호나 이름으로 아무 캐릭터나 골라서 **게임 배경 위에서** 보고(확대, 이동, 조작판, 배경 켬/끔), **투명 GIF** 또는 **배경 넣은 GIF**로 저장 범위를 정해 저장할 수 있어요. 몸 GIF에는 이제 기본으로 빛도 들어가요(빛 따로 뽑기는 고급 설정).
