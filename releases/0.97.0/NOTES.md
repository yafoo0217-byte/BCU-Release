## Stage VS v0.97.0: 카메라 '최전방 자동', 마릿수 표시 겹침

사용자 스크린샷: 카메라가 최전방이 아니라 뒤에 처진 적까지 담는 것처럼 보임 — 원인은 '보이는 폭'이 기본 '전체 맵'이라 맵 전체가 한 화면이었던 것.
- ① 설정의 카메라 시야에 **`최전방 자동`**(새 기본값): 양쪽 최전방 사이 거리 + 여유(1300)에 맞춰 스스로 확대·축소해요(최소 1600). 위치는 원래처럼 두 최전방의 가운데(난투), 뒤처진 적은 따라가지 않아요. 마우스 휠이나 `[` `]`로 직접 확대하면 그때부터 그 크기를 지켜요. 예전 설정의 '전체 맵'은 기본값이었을 뿐이라 한 번만 최전방 자동으로 바뀌어요(설정 화면에서 되돌릴 수 있어요).
- ② 난투의 팀 마릿수 표시(`27/36`, `6/73`)가 두 군대가 섞이면 겹쳤어요 → 겹치면 둘의 가운데를 기준으로 비켜서 보여요.
